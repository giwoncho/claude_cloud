Daily Paper 루틴 — 어떻게 작동하나? Daily Paper Routine — how it works

매일 아침 9시 (Eastern), 누구도 안 누르는데 논문 한 편이 메일로 도착하는 원리 A schematic of why a paper lands in your inbox every 9 AM Eastern without anyone clicking anything

🏗️ 한 장으로 보는 시스템 The system in one diagram

한 줄 요약One-line summary
Anthropic 의 cron 이 매일 13:00 UTC 에 sandbox 를 띄우고, sandbox 안에서 Claude 가 GitHub 에서 받은 instructions 대로 논문을 골라 HTML 을 만든 뒤 GitHub Pages 에 push 하고 Resend 로 메일을 보낸다. 끝나면 sandbox 가 사라진다. Anthropic's cron spins up a sandbox at 13:00 UTC daily; inside, Claude follows instructions pulled from GitHub to pick a paper, generate the HTML, push it to GitHub Pages, and send the email via Resend. The sandbox vanishes when done.

    🔐 비밀 정보가 어디에 어떻게 사는지 Where each secret lives

    핵심 원칙Core principle: 절대로 GitHub repo 에 secret 을 commit 하지 않는다. 비밀은 routine prompt 안에만 살고 (본인 계정으로만 접근 가능), 평문 파일에 저장되지 않는다. No secret is ever committed to the GitHub repo. Secrets live only in the routine prompt (accessible only by your account) and are never written to plain files.

    매일 두 가지 출력이 독립적으로 만들어짐: (A) GitHub Pages 에 publish, (B) Gmail 로 메일 발송. 둘 중 하나가 실패해도 다른 하나는 살아남도록 설계 — 그래서 매일 적어도 어딘가엔 결과물이 남는다. Two outputs are produced independently each day: (A) publish to GitHub Pages, (B) email via Resend. Either one can fail without taking down the other — so the result lands somewhere every day.
